# PayFlow

مطالعه موردی محصول برای یک **کیف پول دیجیتال ledger-first**: هر اثر مالی مرجع، دفترکل دوطرفه، یکتاسازی و پیگیری دارد.

> **دیسکلیمر:** این پروژه سامانه بانکی دارای مجوز نیست، سرویس مالی واقعی ارائه نمی‌دهد و هیچ پول حقیقی جابه‌جا نمی‌کند. کیف پول تعاملی یک sandbox در مرورگر است.

**لینک لایو:** _(بعد از دیپلوی اینجا بگذارید)_

## چه می‌بینید

### سایت معرفی (`/`)
کیس‌استادی محصولی با مسئله، اصول، سفر کاربر، دفترکل، همزمانی، قواعد، قابلیت‌ها، لایه‌ها، قرارداد API، معیارها، مرز محصول و واژه‌نامه.

### کیف پول تعاملی (`/wallet`)
دموی کامل روی همان قاعده‌های هسته:

| لایه | رفتار |
|---|---|
| هسته | موجودی، شارژ، انتقال فردبه‌فرد، تاریخچه، عملیات |
| هویت | احراز هویت پله‌ای با سامانه بیرونی شبیه‌سازی‌شده |
| دارایی | جیب چندارزی، رمزارز امانی، صندوق با تسویه تأخیری |
| اعتبار و کارت | اعتبار اقساطی، جریمه دیرکرد، کارت فیزیکی |
| مرز و پذیرندگی | حواله بین‌المللی با بازبینی انطباق، تسویه دسته‌ای |

هر کارمزد تجزیه می‌شود (نرخ پله‌ای، تخفیف حجم، کف/سقف، VAT فقط روی کارمزد) و سطر مقابلش در دفتر داخلی می‌نشیند.

## اجرا

پیش‌نیاز: Node.js 20+

```bash
npm install
npm run dev
```

باز کنید: [http://localhost:3000](http://localhost:3000)

ساخت تولید:

```bash
npm run build
npm start
```

بررسی کیفیت:

```bash
npx tsc --noEmit
npm run lint
npm test
npm run test:e2e
```

- `npm test` — تست واحد برای `applyLines` و موتور کارمزد
- `npm run test:e2e` — smoke با Playwright روی Microsoft Edge محلی
- CI گیت‌هاب روی `main`: typecheck + lint + unit + build

صفحهٔ کوتاه کیس‌استادی: [`/about`](./app/about/page.tsx)

## ورود نمونه

در `/wallet`:

- موبایل: `09101112276`
- گذرواژه: `payflow1234`

دکمه‌های مفید داخل دمو:

- **پر کردن اطلاعات نمونه** روی صفحه ورود
- **راهنما** برای سه مسیر کوتاه پیشنهادی
- **سناریوهای آماده** روی پیشخوان: انتقال ساده، ارتقای هویت، حواله با بازبینی
- **بازنشانی** برای برگشت به حالت اولیه (با حفظ ورود سارا)
- وضعیت دمو در `localStorage` می‌ماند تا رفرش کار را خراب نکند؛ بازنشانی آن را پاک می‌کند

### سه مسیر پیشنهادی

1. **انتقال ساده** — به کیان منتقل کنید، بعد همان درخواست را تکرار کنید تا یکتاسازی دیده شود.
2. **ارتقای هویت** — خدمات → احراز هویت → سطح ۳ با کد ملی نمونه.
3. **یک لایه پیشرفته** — دارایی‌ها یا خدمات (اعتبار، کارت، حواله، تسویه).

## معماری کوتاه

- Next.js App Router + React + TypeScript
- State کیف پول با `useReducer` و ماژول‌های خالص:
  - `lib/catalog.ts` — ارز، دارایی، صندوق، مسیر حواله، سطوح KYC
  - `lib/fees.ts` — موتور کارمزد قابل‌بازرسی
  - `lib/wallet-core.ts` — اتمی بودن سطرهای دفترکل
  - `lib/wallet-advanced.ts` — هشت دامنهٔ گسترش‌یافته
- فونت‌ها self-host شده‌اند (`app/fonts`)؛ بیلد به Google Fonts وابسته نیست
